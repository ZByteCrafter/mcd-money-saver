# 麦门省钱军师 · mcd-money-saver

> 基于麦当劳中国 MCP 的 35 个工具打造的 WorkBuddy 省钱 Skill：巡券、凑单比价、活动雷达、积分优化、营养参谋，一条龙帮你把每一分钱花在麦麦的刀刃上。

**麦当劳程序员创意开发大赛参赛作品**，由参赛者独立开发，非麦当劳官方产品。

## 这是什么

「麦门省钱军师」是一个可直接安装的 [WorkBuddy Skill](https://www.workbuddy.cn/)：它把麦当劳中国官方 MCP（`mcd-mcp`）的点餐、优惠券、活动日历、积分商城能力，编排成 5 条决策工作流，让 AI 替你完成「有什么券 → 怎么搭配最省 → 去哪家店 → 点什么」的完整决策，而不是简单地罗列接口。

```
用户说"怎么点最省"
   │
   ▼
定位门店 ──► 拉门店可用券 ──► 拉在售菜单 ──► calculate-price 权威计价
   │                                                      │
   └── 活动日历/积分商城补充建议 ◄── 逐券试算 + 叠加试算 ◄───┘
                       │
                       ▼
              输出比价表 + 行动清单 + 点餐方案（不自动下单）
```

## 功能特性

| 功能 | 说明 |
|---|---|
| 一键巡券 | 麦麦省可领券盘点 + 卡包资产 + 临期预警，确认后一键领取 |
| 凑单比价 | 以 `calculate-price` 为唯一价格裁判，逐券试算 + 高价值券叠加，输出比价表 |
| 活动雷达 | 当月活动日历时间线，高亮 7 天内可参与的活动 |
| 积分优化 | 可用/即将过期积分盘点 + 商城兑换性价比建议 |
| 营养参谋 | 餐品营养成分（能量/蛋白质/脂肪/碳水/钠/钙）接入搭配决策 |
| 点餐方案 | 生成完整点餐方案（门店/商品/用券/价格明细），**用户确认后才下单** |

## 快速开始

### 1. 申请麦当劳 MCP Token

前往 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp)，手机号登录后在控制台激活 Token。

### 2. 配置 MCP 连接器

**WorkBuddy**：左侧边栏【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】，粘贴本仓库的 `mcp-config.example.json` 内容并替换 Token，保存后启用。

**其他 MCP 客户端**（Cherry Studio / Cursor / Trae 等）：同样使用 `mcp-config.example.json`，将 `${MCD_MCP_TOKEN}` 替换为实际 Token。

### 3. 安装 Skill

把本仓库目录放入 WorkBuddy 技能目录（任选其一）：

```bash
# 用户级技能（跨项目可用）
cp -r mcd-money-saver ~/.workbuddy/skills/

# 或在 WorkBuddy 中通过技能管理界面导入
```

然后在对话中直接说：「帮我看看麦当劳有什么券能领」「我想点麦辣鸡腿堡和薯条，怎么最省」「最近麦麦有什么活动」。

### 4. 命令行工具（无需 AI，直接跑）

仓库附带两个零依赖 Python 脚本（仅标准库，Python 3.8+）：

```bash
export MCD_MCP_TOKEN=<你的Token>

# 巡券报告（只读）
python scripts/sweep_coupons.py

# 凑单比价（只读，权威计价）
python scripts/combo_optimizer.py \
    --store 1450724 --be-type 1 --order-type 1 \
    --reserve "2026-10-27 11:30" \
    --items 521952:1,521986:1 \
    --coupons <券Id>:<券Code>
```

`python scripts/mcd_mcp_client.py list-tools` 可直接查看当前在线的 35 个工具。

## 工作流设计

| 工作流 | 触发说法 | 调用链 |
|---|---|---|
| W1 巡券 | 「有什么券能领」「券快过期了」 | now-time-info → available-coupons → query-my-coupons →（确认后）auto-bind-coupons |
| W2 凑单比价 | 「怎么点最划算」「多少钱」 | query-nearby-stores → query-store-coupons → query-meals → calculate-price（多轮试算） |
| W3 活动雷达 | 「最近有什么活动」「积分能换什么」 | campaign-calendar → query-my-account → mall-points-products |
| W4 营养参谋 | 「减脂期能吃啥」「热量低的」 | list-nutrition-foods →（搭配后）calculate-price |
| W5 点餐方案 | 「帮我点」「我要下单」 | 汇总 W1–W4 → 生成方案 → 用户确认 → create-order |

## 安全设计

- **只读优先**：7 个变更类工具（领券/下单/取消订单/新增地址/抽奖/积分兑换/主题活动下单）必须经用户明确确认后才调用，调用前复述操作后果。
- **不编造数据**：订单号、券码、门店与商品编码一律来自工具返回或用户提供。
- **限流友好**：遵守每 Token 每分钟 600 次请求限制，比价脚本内置调用间隔与轮次上限。
- **隐私边界**：Token 只从环境变量或连接器配置读取，仓库内仅存环境变量占位符；不输出完整手机号与详细地址。
